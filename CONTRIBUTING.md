# Как помочь проекту

Спасибо за интерес к PDFMaker Mobile. Ошибки, предложения и изменения принимаются
в [Issues](https://github.com/aleksandreev2/pdef/issues) и Pull Requests.

## Сообщить об ошибке

Укажите версию PDFMaker и Windows, шаги воспроизведения, ожидаемый и фактический
результат. Для проблем с импортом или оформлением пригодится небольшой пример
исходника и фрагмент отчёта. Перед публикацией удалите личные данные; для примера
достаточно вымышленного текста, который воспроизводит ошибку.

## Предложить улучшение

Опишите задачу пользователя и ожидаемое поведение. Для заметного изменения
интерфейса или формата книги сначала удобно обсудить его в Issue.

## Подготовить Pull Request

1. Создайте fork и ветку от `main`.
2. Установите зависимости и шрифты по [инструкции](docs/development.md).
3. Внесите изменения. Для исправлений поведения добавьте проверку исходной ошибки.
4. Выполните `npm test`; при изменении интерфейса проверьте соответствующий сценарий Electron.
5. Опишите проблему, результат и выполненные проверки. Обновите документацию,
   если меняются доступные пользователю возможности.

Сохраняйте исходный литературный текст: автоматическая обработка исправляет
технические дефекты, а не переписывает произведение. Не добавляйте в репозиторий
пользовательские книги, `node_modules`, собранные установщики и секреты.

Код проекта распространяется под [MIT](LICENSE). При добавлении сторонних
ресурсов сохраняйте их лицензии и авторские уведомления.
