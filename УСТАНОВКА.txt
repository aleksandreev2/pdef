PDFMaker Mobile — установка
===========================

ОБЫЧНАЯ УСТАНОВКА НА WINDOWS
---------------------------
1. Откройте https://github.com/aleksandreev2/pdef/releases/latest
2. Скачайте PDFMaker-Mobile-3.3.1-Setup.exe и запустите его.

Windows 10/11, 64 бит. Шрифты, библиотеки и Calibre уже включены.
Node.js и консоль для установленной программы не нужны.

ЗАПУСК ИЗ ЭТОГО АРХИВА ИСХОДНИКОВ
--------------------------------
Нужен Node.js 20 или новее: https://nodejs.org
Распакуйте архив в папку с правом записи. Откройте терминал в этой папке:

    npm ci
    npm run fonts
    npm start

Для экспорта MOBI/AZW3 из исходников установите Calibre или выполните
в Windows: npm run kindle-tools

ПЕРВАЯ КНИГА
------------
1. Перетащите главы, папку или ZIP в приложение.
2. Укажите название, команду перевода и обложку.
3. Проверьте «Аудит»: порядок, пропуски, пустые файлы и дубли.
4. Выберите оформление, форматы, иллюстрации и папку вывода.
5. Нажмите «Собрать книгу», откройте «Отчёт» и «Предпросмотр».

ОБНОВЛЕНИЕ
----------
С версии 3.3.0 приложение сообщает о новых релизах GitHub.
«Обновить» скачивает и проверяет установщик, затем запускает установку.
Сохраните результаты перед обновлением: приложение закроется.
Настройки установленной программы сохраняются.
