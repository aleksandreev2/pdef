# История версий

Готовые установщики и файлы проверки — в [релизах GitHub](https://github.com/aleksandreev2/pdef/releases).

## 3.3.2

- Исправлены закладки в структуре PDF: выбор главы теперь открывает её страницу,
  а не последнюю страницу книги.
- Добавлен автоматический тест переходов по закладкам на титульную страницу,
  оглавление, сведения о переводе и три разные главы.
- Уже созданные PDF нужно пересобрать обновлённой версией.

## 3.3.1

- На титульной странице PDF добавлены «Создано в PDFMaker Mobile» и видимый
  кликабельный адрес `github.com/aleksandreev2/pdef`.
- При размещении подписи команды перевода резервируется место для подписи
  приложения: длинные названия переносятся, а нулевой нижний отступ не приводит
  к перекрытию подписей.
- Подпись отображается в настоящем PDF-образце ручного оформления.
  Для уже созданных книг нужна пересборка из исходников.

## 3.3.0

### Добавлено

- Уведомление о новых стабильных релизах из `aleksandreev2/pdef`: при запуске
  и раз в шесть часов, пока открыто приложение.
- Обновление из приложения: подтверждение, прогресс загрузки, проверка размера
  и SHA-256, запуск Windows-установщика. Настройки сохраняются.
- Ручная проверка, отключение автоматической проверки и запоминание отложенного релиза.
- Сжатие иллюстраций в двух режимах и экспорт версий с иллюстрациями,
  без иллюстраций или обеих сразу. Обложка сохраняется по умолчанию.
- Предупреждения о пропущенных номерах глав, пустых и повреждённых файлах.
  Проверка учитывает текущий выбор глав, замечания сохраняются в отчёте.

### Исправлено

- Записи персонажей: отдельные строки для полей и вероятности, выделенные
  подписи, отступы в PDF. Скобки сохраняются как в исходнике; переносы слов
  по слогам внутри таких записей отключены.

### Документация

- README с установкой, быстрым стартом, примерами и ответами на частые вопросы.
- Руководства для пользователей и разработчиков, MIT LICENSE, сведения о
  сторонних компонентах и шаблоны обращений.

## 3.2.0

- Перенос длинных названий команд и подписей перевода с сохранением ссылок.
- Жанр «Эротика»: винный акцент, сливовая обложка, кружево и ленты.
- Ручная настройка титула и страницы «О переводе» в PDF: кегли, отступы,
  ширина орнамента, автоматический образец, предупреждения, отмена и сброс.
- Сохранены встроенный Calibre, шрифты и автономная установка для Windows.
