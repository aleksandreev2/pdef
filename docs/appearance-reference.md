# Оформление по утверждённому визуальному образцу

Визуальная цель: приложенная пользователем сетка 10 жанров (Изображение ChatGPT 3 окт, 2026 г,, 17_24_31-Picsart-AiImageEnhancer.png).
Бэкап исходной версии 70006f6: ../../output/appearance-backup/PDFMaker-appearance-before-reference-2026-10-03.zip.

Реализация: 10 детальных векторных профилей. Единые SVG для рамки страницы, орнамента главы, разделителя сцены, иконки записи, уголков панели и фолио. PDF сохраняет выделяемый текст; EPUB остаётся reflowable. FB2 использует PNG-орнаменты в пределах возможностей формата; TXT plain, MOBI имеет ограничения старых читалок.

1. Органические профили: fantasy, horror, romance, historical, cultivation — artwork/organic.js.
2. Геометрические профили: dark-fantasy, sci-fi, litrpg, thriller, regression — artwork/geometric.js.
3. Общий адаптер signature.js, PDF layout/render, EPUB templates и образец интерфейса.
4. Реальные PDF/EPUB всех десяти жанров; визуальная сетка именно от PDF, проверка переноса текста/длинных блоков/отключения орнаментов и всех форматов.
5. Независимая проверка кода, установка обновления Desktop с сохранением бэкапа, push в pdef.

Контракт artwork(genre, part, accent): SVG inner markup без текста и внешних ресурсов. Координаты: opener 1000×280, divider 1000×160, frame 1000×1778, icon 100×100, corner 100×100, folio 1000×100. part frame только рамка и углы; крупный центральный орнамент отдельно opener. Полоса тела x90..910,y320..1640 свободна от рамки; header art y<=270. Углы не дублируют разделитель. Фолио оставляет x430..570 пустым для настоящего номера страницы. Размеры layout и фактические renderer высоты согласованы.

Решение: переносить векторное оформление по выбранному пользователем образцу без повторного согласования дизайна; пользователь прямо просит добиться этого вида и разрешил библиотеки. Подключение новых зависимостей с точной версией и проверкой реального PDF.


Проверка завершена: 66/66 тестов; PDF и EPUB всех 10 жанров проходят QA.
Настоящий интерфейс проверен по 10 жанрам, смене акцента и отключению орнаментов.
Новелла из 113 глав собрана во все 6 форматов (PDF: 1895 страниц); проверка и
автоматический предпросмотр завершились без краша. Исходные файлы неизменны.
Независимая проверка обнаружила выход рамки при полях 9 мм и длинных названий
за страницу. Исправлены геометрическим clipPath и адаптивным кеглем с переносом
исключительно длинных заголовков. Повторная проверка исправлений без замечаний.
